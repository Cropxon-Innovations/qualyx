# QUALYX - Autonomous QA-as-a-Service

QUALYX is an AI-powered testing platform for modern engineering teams. Self-healing tests, session replay, and 10x faster test creation.

## About

QUALYX is a product by [Cropxon Innovations Pvt. Ltd.](https://cropxon.com)

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Cloud Backend)

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```
